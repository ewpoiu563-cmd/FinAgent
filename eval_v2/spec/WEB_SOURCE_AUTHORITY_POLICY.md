# Web 来源策略与权威性判定

## 先识别用户约束，再选择来源

`只使用证监会官网`、`不要媒体转载`、`仅限某域名` 是本次请求的硬约束：检索结果会按允许域名过滤，子问题和 SQL 失败后的 Web 补充也继承该约束。它不是全局默认设置。

没有明确来源限制时，系统采用开放检索与领域感知排序，不能因为问题不是金融问题就只搜索监管网站。

## 开放检索的来源层级

| 问题 / 主张 | 首选证据 | 补强规则 |
|---|---|---|
| 法规、监管动作、公共政策 | 对应政府或监管机构原文 | 标注发布日期与生效日期，媒体只作线索 |
| 上市公司、基金披露、股东与财务数字 | 交易所 / 监管披露、发行人公告或 IR | 数字必须带报告期；转载不能替代原件 |
| 行情、汇率、实时价格 | 指定交易所、数据供应商或产品官方页 | 必须给时间戳和市场口径 |
| 医疗、科学、高风险建议 | 官方指南、同行评审原始研究 | 不把一般网页当诊疗/法律/投资结论 |
| 一般事实和时效新闻 | 事件当事方、机构原文或有编辑责任媒体 | 关键争议事实至少两家独立来源交叉核验 |
| 主观推荐 / 经验性问题 | 明示依据、时间和局限 | 不伪称“唯一权威答案” |

每条引用会记录域名、是否为一手来源、主张类型和时间；评测以 Citation Entailment、引用支持率和 Web 忠实度检查它是否真正支持答案，而非仅检查链接存在。
